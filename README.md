# StoryFlow

StoryFlow 是一款為影視創作者量身打造的專業分鏡表（Storyboard）製作軟體。它提供直覺且高效的操作介面，幫助導演、攝影師與製片團隊輕鬆規劃與管理每一個鏡頭細節。

## 🌟 軟體特色與功能

1. **視覺化分鏡管理**：
   - 支援為每個鏡頭上傳參考圖片或手繪分鏡圖。
   - 提供直覺的拖曳排序功能（Drag and Drop），隨時調整鏡頭順序，靈活對應劇本變更。

2. **專業影視參數設定**：
   - 內建豐富的**景別與運鏡**選項（如：特寫 CU、推軌 Dolly、平視角 Eye Level 等），標準化影視語言。
   - 精確的**鏡頭時長**紀錄（分與秒）。
   - 獨立的**畫面內容**、**聲音（對白/音效/音樂）**及**備註（特效/道具）**欄位，讓劇組溝通零誤差。

3. **專屬檔案格式**：
   - 支援儲存為專屬的 `.sf`（StoryFlow Document）格式，方便專案備份與團隊間的檔案交換。
   - 輕鬆匯入與匯出專案資料。

4. **便捷的列印輸出**：
   - 內建列印模式，支援 A4 或 A3 紙張大小。
   - 提供彩色與黑白列印選項，快速輸出實體分鏡表帶至拍攝現場使用。

## 🛠 使用的程式技術

StoryFlow 採用現代化的前端技術棧與跨平台桌面應用框架開發，確保高效能與良好的開發體驗：

### 核心框架與工具
* **React 18**：負責建構豐富且互動性強的 User Interface。
* **TypeScript**：提供嚴格的型別檢查，提升程式碼品質與維護性。
* **Vite**：極速的前端建置工具，提供流暢的本地開發與模組打包體驗。

### 桌面端技術
* **Electron**：將 Web 應用封裝為原生桌面應用程式（Windows, macOS, Linux），提供接近原生的使用體驗。
* **Electron-builder**：負責打包與發布應用程式，並設定專屬的檔案關聯（如 `.sf` 副檔名）。

### 關鍵套件
* **@hello-pangea/dnd**：實現流暢的清單拖曳與鏡頭重新排序功能。
* **lucide-react**：提供簡潔美觀的開源向量圖示庫，提升介面質感。

## 📥 如何下載與安裝

您可以直接從 GitHub 的 Releases 頁面下載最新版本的應用程式：

1. 點擊進入本專案的 [Releases 頁面](https://github.com/sutimlong/StoryFlow/releases)（您也可以在專案首頁右側找到「Releases」標籤並點擊）。
2. 在頁面中尋找標示為 **Latest** 的最新版本。
3. 展開該版本下方的 **Assets** 區塊，並根據您的電腦系統下載對應的檔案：
   - **macOS 使用者**：請下載結尾為 `.zip` 的檔案，解壓縮後直接開啟或將 StoryFlow 拖曳至您的「應用程式 (Applications)」資料夾。
   - *(其他作業系統如 Windows，若有提供 .exe 等格式，亦可在此下載)*。
4. 檔案下載並安裝（或解壓縮）完成後，點擊 StoryFlow 應用程式圖示即可開始製作您的分鏡表！

> **⚠️ macOS 安全性提示**：由於軟體為獨立開發，首次開啟時可能會遇到「無法打開，因為無法驗證開發者」的系統提示。此時請前往 Mac 的「系統設定 > 隱私權與安全性」，捲動到底部點擊「強制打開（Open Anyway）」即可正常使用。
